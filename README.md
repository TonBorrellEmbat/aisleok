# AisleOK

US-first iOS aisle checker. Scan a barcode, photograph a label, or type a produce name. Eat / small portion / skip / unknown.

This repo holds the locked v1 drop-ins. The Xcode binary is not here yet.

- `AisleOK_trigger_tags_v1.json` — 103 tags / 186 aliases
- `privacy.html` / `terms.html` — App Store policy pages
- `assets/` — icon-1024.png and five 1290×2796 store frames

Not a medical device. Not Monash. Not embatio/embat-dwt.
